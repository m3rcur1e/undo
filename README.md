# Undo

Ctrl+Z undoes your last build actions, Ctrl+Shift+Z redoes them, many steps back. Placed blocks are taken down again, deconstructed ones come back with their rotation and settings, cancelled plans return, schematic pastes go away in one step.

![Undo](https://raw.githubusercontent.com/m3rcur1e/undo/media/undo.webp)

![Undo a deconstruction](https://raw.githubusercontent.com/m3rcur1e/undo/media/undo-break.webp)

### Customizable

In **Settings › Undo** (or **Cur1e Mods**):

- undo history depth (10–200 actions, default 50)

In **Settings › Controls › Undo**:

- undo, with Ctrl (default Z)
- redo, with Ctrl + Shift (default Z; a key other than undo's also works with just Ctrl, e.g. Ctrl+Y)
